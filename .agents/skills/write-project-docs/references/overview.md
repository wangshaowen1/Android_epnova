# 项目导览模板

用于 docs/README.md。它只负责建立项目心智模型和阅读路由，不重复根 README 的环境搭建，也不展开具体设计。

```markdown
# <项目名>文档

## 项目职责

用一个短段落说明产品用途和当前仓库的系统职责。

## 系统地图

| 领域 | 职责 | 稳定代码锚点 | 详细文档 |
| --- | --- | --- | --- |

只列理解和导航仓库所需的主要领域。

## 关键流程

只保留定义项目心智模型的少量核心流程。

## 核心约束

列出容易被破坏、重新发现成本高的长期不变量；原因放在对应架构文档。

## 有效文档

| 文档 | 用途 | 状态 | 实现状态或适用范围 |
| --- | --- | --- | --- |

## 推荐阅读路径

- 新开发者：给出建立项目认知的最短顺序。
- 任务型 AI：按任务类型指出需要加载的一份或少量文档。
```

不要列完整模块树、完整 API、每个页面、版本历史或与根 README 重复的内容。
