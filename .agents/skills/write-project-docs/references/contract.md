# 契约文档模板

用于多个模块或系统共同依赖的接口、事件、数据和状态语义。OpenAPI、Apikit、Proto 或等价 Schema 已能完整表达的结构，直接链接，不在 Markdown 重复维护。

```markdown
# <契约名称>

## 目标与权威范围

说明生产者、消费者、约束行为，以及本文与 Schema、代码和产品资料各自负责的事实。

## 范围与非目标

排除数据库物理结构、界面实现和编码步骤。

## 公共语义与不变量

记录 ID、空值、顺序、状态归属、可见性、一致性和兼容规则。

## 接口、事件或数据模型

按业务能力组织最小必要的请求、响应、事件或字段语义。

## 状态变化与失败行为

描述幂等、并发、错误、重试和恢复中会影响消费者实现的行为。

## 版本与兼容

说明契约身份、兼容边界、迁移条件和旧数据处理；没有特殊规则则省略。

## 联调与验证

列出参与方可共同观察的验收条件或契约测试。

## 待确认问题

只列会改变契约的问题；没有则省略。
```

权威 Schema 尚未建立时，Markdown 可以暂时定义必要字段。每个结构只保留字段表、完整示例或类型定义中的一种规范表示；Schema 建立后删除重复结构，只保留业务不变量、兼容和失败语义。
